근거: **(260804) 신용취약소상공인자금 운용지침 개정 전문.hwp**, 본문 최종 개정일 **2026-08-04**. 제1절 개요, 제2절 대출제한대상, 제3절 제출서류, 제4절 대출절차를 대조했다. HWP 추출문에 페이지·병합표 열 경계가 없으므로 근거는 절·항목으로 표시한다.

## 혼동을 방지한 기준

- NCB 839점 이하는 신청 당시 개인신용평점이며 NICE SOHO ML 기업등급과 다르다. 840점은 신청 점수 상한을 초과한다.
- 업력 90일은 포함한다. 개업일이 사업자등록일 전이면 등록 전 기간은 최대 20일 인정한다.
- 기업등급 9~10등급의 연매출 1억 9,700만원 미만 제한과 실사 기준 연매출 2,000만원 이하는 서로 다른 기준이다.
- 관련 2023~2026 자금 잔액을 차감하고 신청가능액 최소 1,000만원을 확인한다. 3,000만원 상한은 개별 승인액이 아니다.
- 기업등급별 3,000·2,500·2,000·1,500만원의 정확한 열 대응은 원문 병합표 대조가 필요하여 임의로 배정하지 않았다.
- 최초 온라인 신청 서식, 정책우선도평가 선정 후 서류, 조건별 추가·보완 서류, 약정 자료를 구분한다. 선택 동의를 필수로 바꾸지 않으며 등기서류 생략·유효기간·가림처리 안내를 보존한다.
- 대출제한기준은 2026-07-13 접수 건부터 적용한다. 한계기업·부채비율·차입금 제한의 업력 예외는 7년 이하로, 정확히 7년도 포함한다.
- 정책우선도 미선정은 차기 재신청 가능하며, 동일 연도 동일 자금 심사 부결 등의 6개월 재신청 제한과 구분한다.
- 최초 신청은 온라인, 개인 약정은 전자, 법인 약정은 대면이다. 지역센터 방문을 최초 신청 경로로 안내하지 않는다.

## 구현·수정

- `policy/credit-guide.js`: 화면 코드와 분리된 요약·상세·검색어·항목별 근거. 모든 핵심 카드와 상세 항목에 출처를 지정했다.
- `src/CreditGuide.jsx`, `src/credit-guide.css`: 검색·분류 선택·상세 펼침·전체 인쇄. 검색과 분류는 URL이나 저장소에 기록하지 않는다.
- 상담 상태와 작성 중인 복수 선택은 상위 화면 메모리에 보존하며, 안내 복귀 시 상담 평가를 다시 제출하지 않는다.
- 원본 HWP·추출 전문은 작업용 `docs/sources/`에만 두며 Git·공개 웹·HTML 다운로드에 포함하지 않는다. 공식 링크는 접수·교육 누리집이며 원문 직접 다운로드 링크로 표시하지 않는다.
- 안내 내용은 기존 판단 엔진의 자격 요건을 변경하지 않는다. 변경 시에는 첨부 근거를 확인하고 `npm run build:download`로 웹·HTML·ZIP을 함께 재생성한다.
