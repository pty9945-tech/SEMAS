# 공통 지원조건·제한조건 검토표

**상담 적용 방식(2026-10-19): 소상공인 기본요건을 충족한 것으로 전제합니다.** 아래 근로자 수·소기업 매출·사업자 형태·지위유지 기준은 근거 설명으로 보존하며 일반 확인 질문은 생략합니다. 청년 고용·졸업후보기업 등 자금별 추가요건과 융자제한은 계속 확인합니다.

확인일: 2026-10-15. 사용자가 제공한 HWP에서 추출한 본문을 확인했다. 아래는 상담용 조건 정리이며 개별 자금 지침의 특칙과 심사 결과를 대신하지 않는다. 문서의 내부 업무 지시는 앱의 개인정보 수집·저장 지시로 사용하지 않는다.

## 1. 소상공인 규모

근거: 직접공통 제3장 「소상공인 기준 및 확인방법」, 대리공통 제4장 「소상공인 기준 및 확인 방법」 및 붙임2·붙임3.

### 상시근로자

| 주된 업종 | 기본 기준 | 경계 |
| --- | --- | --- |
| 광업·제조업·건설업·운수업 | 10명 미만 | 9.5명은 기준 이내, 10명은 초과 |
| 그 밖의 업종 | 5명 미만 | 4.5명은 기준 이내, 5명은 초과 |

대표자·임원, 일용근로자, 3개월 이내 기간을 정해 일하는 근로자, 인정 기업부설연구소·연구개발전담부서의 연구전담요원, 월 소정근로 60시간 미만 단시간근로자는 규정에 따라 제외한다. 같은 고용주에게 3개월 계약을 반복하여 계속 일하는 자는 포함한다. 단시간근로자는 월 60시간 이상이면 0.5명으로 산정한다. 연구소의 일반 사무직은 포함한다. 오늘 출근 인원이나 정규직 수만으로 판단하지 않는다.

직전 사업연도가 12개월 이상이면 매월 말일 인원의 합을 12로 나눈다. 창업·합병·분할 등으로 12개월 미만이면 사업기간에 따른 평균 산정규정을 적용한다. 해당월/특정 짧은 기간에는 산정일 현재 인원을 사용하는 경우가 있다. 상담에서는 산정 완료된 수치의 구간을 묻고 산정 전이면 확인 필요로 둔다.

권장 구간: `5명 미만 / 5명 이상 10명 미만 / 10명 이상 20명 미만 / 20명 이상 / 모름`. `0~4명` 표기는 4.5명 같은 유효값을 빠뜨린다.

### 소상공인 지위 유지

규모 확대 등으로 소상공인에 해당하지 않게 된 경우 해당 사유가 발생한 연도의 다음 연도부터 3년간 소상공인으로 본다. 다만 소기업 외 기업과의 합병, 중소기업 해당성 상실, 지위 유지 후 소상공인이 되었다 다시 규모를 넘는 경우, 상시근로자 **20명 이상**, 공시대상기업집단 편입, 지위유지 포기 등 제외사유가 있다.

따라서 5명·10명 또는 매출 경계 초과를 바로 전체 자금 탈락으로 연결하면 안 된다. `기본 기준 초과 → 법정 지위유지 확인 → 확인됨/해당 없음/모름` 분기를 사용한다. 지위유지는 서류로 확인하며 자동 3년 판정을 하지 않는다.

## 2. 사업자 형태·업종

근거: 직접공통 제4장 「영리·비영리기업 기준 및 확인방법」·제5장 「업종분류 방법」, 대리공통 제5장·제6장.

- 개인과세·면세사업자 및 영리법인 본점 등이 기본 대상이다. 영리성을 단순 과세 여부로 판단하지 않는다.
- 비영리법인이라도 인증 사회적기업, 법정 협동조합·사회적협동조합·소비자생활협동조합 등에는 중소기업 인정 예외가 있다. 예비사회적기업 지정만으로 일반 비영리법인을 중소기업으로 인정하지 않는다. 개별 혁신성장 자금의 사회연대경제조직 경로는 해당 자금 특칙 확인이 필요하다.
- 법인격 없는 조합, 외국법인 본·지점, 영리법인 지점 등은 문서상 제외 대상이다. 정보가 불충분한 비영리 조직은 예외 확인으로 남긴다.
- 2개 이상 업종은 매출비중이 가장 큰 실제 영위 주업종을 확인한다. 사업자등록증 업태명만으로 제외 업종 여부를 단정하지 않는다. 산업분류는 세세분류(5자리)를 기준으로 한다.

융자제외 업종 근거: **대리공통 붙임4** 「소상공인 정책자금 융자제외 대상 업종」, 직접공통 제6장 뒤 「참고: 소상공인 정책자금 융자제외 대상 업종」. 대리공통 붙임3은 근로자 산정 제외기준이며 업종표가 아니다.

## 3. 대출 제한 비교

직접공통 제6장 「대출제한기준 및 확인방법」과 대리공통 제7장 「대출 제한기준 및 확인 방법」을 비교했다. 직접공통 제한 대상은 신청기업·개인 공동대표·법인 공동/각자 대표이사·실제경영자·법인 보증인 등이며, 대리공통은 신청기업 및 신청자가 기본이고 공단 관리 제한 외 항목에서는 신청자 외 공동대표 등의 적용 제외가 있다. 개인정보 식별번호를 앱에 수집할 필요는 없으며 상담직원이 해당 관계자까지 확인했는지만 선택한다.

## 4. 한도와 기존 이용

근거: 직접공통 **제10장 「대출한도 운용방법」**, 대리공통 **제11장 「대출한도 운용방법」**.

| 항목 | 확인된 기본 운용 |
| --- | --- |
| 통합 최고한도 | 같은 기업 운전자금 잔액 5억원 이내, 시설 포함 10억원 이내. 직접·대리 잔액 상호 포함 |
| 연간한도 | 지급연도 기준. 당해연도에 실행된 동일 자금 대출잔액 차감 |
| 잔액한도 | 실행된 동일 자금 대출잔액 차감. 실행연도가 달라도 포함 |
| 긴급경영안정 | 통합 최고한도 배제 문구 있음. 실제 해당 세부 자금 지침의 별도 한도·합산 범위 확인 |
| 직접 법인 | 책임경영심사 B등급이면 자금별 운전자금 최고한도의 80% 적용 |
| 동일관계기업 | 실질 지배·사실상 같은 기업 여부를 확인하여 직접·대리 잔액 합산. 지분 50% 등은 관계기업 정의에 사용 |

최고한도에서 잔액을 뺀 값만으로 대출 가능금액을 확정하지 않는다. 자금별 최소 신청액, 신청 단위, 평가·담보·책임경영심사, 동일관계기업, 기존 자금 합산 범위를 확인해야 한다. 숫자 입력이 없는 첫 버전은 `자금별 잔액 확인 완료 / 추가 확인 필요 / 모름`으로 남기고 승인금액으로 표시하지 않는다.

## 5. 질문·검증 설계에 반영할 사항

1. 사업 상태 → 산정된 근로자 구간 → 필요한 업종 → 소기업 매출 확인 → 초과 시 지위유지 → 형태·제외 업종 → 체납·연체 → 자금 목적 → 후보별 제한·특수요건 순으로 공통 탈락·예외를 먼저 확인한다.
2. 복잡한 제한표 전체를 `확인함` 하나로 대신하는 경우 원문 항목을 펼쳐 보고 판단할 수 있게 해야 한다. 그렇지 않으면 해당 조건을 미확인으로 결과에 남긴다.
3. `모름`, `예외 확인`, `일부 대상자 미확인`은 미충족이 아니다. 직접공통 조건을 예외가 있는 모든 직접자금에 동일 적용하지 않는다.
4. 검증 경계: 근로자 4.5/5/9.5/10/19.5/20, 매출 정확한 기준값, 소상공인 지위 유지와 종료, 업력 정확히 7년, 부채비율 700%, 차입금/매출100%, 연체 29/30일 및 9/10일·3/4회, 같은 해 6개월 경과, 지원 2/3회와 예외, 잔액·최소신청액 경계.
5. 정책 문서의 요구 서류와 내부 보존기간은 실제 대출기관의 처리 기준이다. 이 상담 보조 앱의 저장·개인정보 수집 기능을 추가하는 근거로 사용하지 않는다.
