- 재해직접은 단순 납기연장으로 충족하지 않으며 지정 체납처분 유예 등이 필요. 재해로 인한 휴업 예외 검증.
- 사관학교 경로의 시설자금 제외·별도 업종제한, 다른 혁신 경로 동시 충족, 졸업후보기업의 지위유지 제외 검증.
- 선투자 추천서·재도전 세부 증빙 미확인은 확인 필요로 남김. 일부 자금 제한을 모든 후보 탈락으로 확장하지 않음.
- 이메일 8자리 일회용 번호·만료·재사용·실패 횟수·요청 제한·보안 쿠키·정확한 요청 Origin 검증.
- 미초대자 상담 API 401, 일반 이용자 관리자 API 403, 권한 회수 후 기존 세션·미사용 코드 즉시 무효화.
- 1440px/390px PC·모바일, 키보드 선택·모달 포커스·Escape, 결과 복사·인쇄, 선택 및 결과에 관한 브라우저 저장소·URL 저장 없음.

숫자 경계는 실제 질문의 공고 구간과 조건식의 포함/미포함을 검증했다. 복잡한 서류 판독, 지정지역 증명, 동일관계기업·심사 예외는 사람의 확인 답변을 전제로 하며 자동 심사를 검증했다는 뜻이 아니다.

## 아직 실행하지 못한 외부 검증

호스팅 계정·공개 HTTPS 서비스·실제 인증메일 발송 연결이 없어 **운영 사이트 배포 및 실제 수신 이메일로 로그인·차단·회수 검증은 미실행**이다. 테스트는 동일 서버의 테스트용 전송기를 사용했다. 운영용 인증 우회나 메일함 API는 없다.

첨부 문서로 정책조건을 확인했지만 현재 접수·예산 소진·이후 변경공고는 확인하지 않았다. 최고한도는 승인금액이 아니며 승인 확률을 산출하지 않는다. [자료 확인 기록](source-review.md), [배포에 필요한 연결](deployment.md)을 참고한다.

재사용 `install_script`는 보존했고 공식 자료 반영 상태와 시작·검증 방법을 포함한 `start_skill`을 환경 설정 초안에 저장했다. 초안 저장은 웹사이트 배포나 실행 환경 게시를 뜻하지 않는다.
