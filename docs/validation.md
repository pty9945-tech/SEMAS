# 공개형 전환 후 검증

사용자의 최신 요청에 따라 로그인·초대 없이 누구나 이용하는 정적 사이트를 기본으로 전환했다.

- 공개형 프로덕션 빌드 성공.
- 공개형 Chromium 검사 **5개 통과**: 즉시 상담 진입, 정상·복수 후보, 이전 답 수정, 폐업·모름, 복사·인쇄, 모바일, `/SEMAS/` 하위 경로.
- 브라우저 네트워크 검사에서 상담 API 요청 **0건**. 쿠키·localStorage·sessionStorage·URL에 상담 데이터 없음.
- 기존 비공개형 Chromium 검사 **6개 통과** (`npm run test:e2e:private`).
- GitHub Pages 게시 성공: [실행 기록](https://github.com/pty9945-tech/SEMAS/actions/runs/38739078085).
- 실제 HTTPS 사이트에 대한 동일한 공개 브라우저 검사는 GitHub Actions `Verify public consultation site`에서 실행한다.

아래는 같은 정책·인증 엔진에 대한 기존 상세 검증 기록이다. 이전 서버의 SMTP·호스팅 미연결 항목은 비공개 서버에 대한 당시 상태이며 현재 공개 사이트의 배포 상태를 나타내지 않는다.

## 검증한 주요 경로

- 정상 운영 상담에서 일반경영안정자금 유지, 탈락한 자금의 추가 질문 생략.
- 장애 증빙·청년 대표 조건을 함께 충족하면 일반·장애인·청년 자금이 동시에 남음.
- 폐업이면 불필요한 질문 없이 종료. 대환만 선택하면 첨부 범위에 해당 자금이 없음을 표시.
- 모름은 미충족이 아님. 사업상태·용도 확인 후에도 모르면 추가 확인으로 종료. 이미 충족한 OR 경로의 불필요한 추가 질문은 생략.
- 이전 답 변경 시 이후 답변 제거. 서버에서도 경로를 다시 재생해 오래된 답·개인식별정보 필드를 무시.
- 근로자 평균 4.5/5/9.5/10/19.5/20명, 법정 지위유지 및 20명 상한 검증.
- 청년 만39/40세, 업력3년 경계 및 청년 고용 대체 경로 검증.
- NCB839/840, 인정 업력90일, 신용교육, 기업등급9~10의 매출1억9700만원 경계 및 최소 신청가능액 확인.
- 일시경영 직접의 매출1억400만원·업력7년 경계에서 대리대출 후보는 유지. 매출감소 예외 경로 확인.
- 재해직접은 단순 납기연장으로 충족하지 않으며 지정 체납처분 유예 등이 필요. 재해로 인한 휴업 예외 검증.
- 사관학교 경로의 시설자금 제외·별도 업종제한, 다른 혁신 경로 동시 충족, 졸업후보기업의 지위유지 제외 검증.
- 선투자 추천서·재도전 세부 증빙 미확인은 확인 필요로 남김. 일부 자금 제한을 모든 후보 탈락으로 확장하지 않음.
- 이메일 8자리 일회용 번호·만료·재사용·실패 횟수·요청 제한·보안 쿠키·정확한 요청 Origin 검증.
- 미초대자 상담 API 401, 일반 이용자 관리자 API 403, 권한 회수 후 기존 세션·미사용 코드 즉시 무효화.
- 1440px/390px PC·모바일, 키보드 선택·모달 포커스·Escape, 결과 복사·인쇄, 선택 및 결과에 관한 브라우저 저장소·URL 저장 없음.

숫자 경계는 실제 질문의 공고 구간과 조건식의 포함/미포함을 검증했다. 복잡한 서류 판독, 지정지역 증명, 동일관계기업·심사 예외는 사람의 확인 답변을 전제로 하며 자동 심사를 검증했다는 뜻이 아니다.

## 이번에 수정한 사항

- 가상 자금·조건을 첨부된 2026년 10종 자금으로 교체하고 근거 문서·항목을 연결했다.
- 상시근로자의 소수 평균 인원, 소상공인 지위유지, 자금별 유예·휴업 예외를 구분했다.
- 신용취약의 등록 전 업력 보정을 다른 자금에 적용하지 않도록 질문을 분리했다.
- 매출감소 비교기간에 연도를 포함했고 대리·직접 모두 적용했다.
- 근거 배열을 잘못 렌더링해 문서명이 빠지던 화면을 수정하고 질문별 기준표·설명을 펼쳐볼 수 있게 했다.
- 재해별 특별조건의 사건명·금리와 결과 복사에 포함되는 세부 유형을 보완했다.

## 아직 실행하지 못한 외부 검증

호스팅 계정·공개 HTTPS 서비스·실제 인증메일 발송 연결이 없어 **운영 사이트 배포 및 실제 수신 이메일로 로그인·차단·회수 검증은 미실행**이다. 테스트는 동일 서버의 테스트용 전송기를 사용했다. 운영용 인증 우회나 메일함 API는 없다.

첨부 문서로 정책조건을 확인했지만 현재 접수·예산 소진·이후 변경공고는 확인하지 않았다. 최고한도는 승인금액이 아니며 승인 확률을 산출하지 않는다. [자료 확인 기록](source-review.md), [배포에 필요한 연결](deployment.md)을 참고한다.

재사용 `install_script`는 보존했고 공식 자료 반영 상태와 시작·검증 방법을 포함한 `start_skill`을 환경 설정 초안에 저장했다. 초안 저장은 웹사이트 배포나 실행 환경 게시를 뜻하지 않는다.
