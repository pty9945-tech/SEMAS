# 동작센터 정책자금 상담 도우미

**[사이트 바로 열기](https://pty9945-tech.github.io/SEMAS/)**

**[HTML 파일 받기](https://pty9945-tech.github.io/SEMAS/download.html)** · [ZIP 바로 받기](https://pty9945-tech.github.io/SEMAS/downloads/dongjak-policy-helper.zip)

누구나 로그인 없이 웹브라우저에서 질문을 선택하고 정책자금 검토 결과를 볼 수 있습니다. 사용자의 요청에 따라 초대·이메일 인증 없이 이용하는 공개형을 기본으로 제공합니다. 별도 프로그램·메일 서비스·서버·환경변수 설정이 필요 없습니다.

## 이용 방법

1. 소상공인 기본요건을 충족한 것으로 보고, 자금 사용 목적부터 선택합니다. 기본 근로자 수·업종별 소기업 매출·사업자 형태·지위유지는 다시 묻지 않습니다.
2. 각 선택지 아래 연관 자금명을 볼 수 있습니다. 목록이 길면 나머지 자금을 펼쳐 확인합니다. 자금별 추가 매출·청년 고용·졸업후보 요건과 체납·연체·제외업종 등은 계속 확인합니다. 해당되는 목적·특별요건이 여러 개면 복수로 선택합니다. 모르는 조건은 확인 필요로 남깁니다.
3. 하나를 고르는 질문은 선택 즉시 다음으로 이동합니다. 여러 항목을 고르는 질문과 숫자 입력은 답을 완성한 뒤 **다음 질문**을 누릅니다. **이전 질문**은 질문·결과 화면 모두에서 사용할 수 있으며 이전 답이 선택된 상태로 돌아갑니다. 답을 바꾸면 이후 답변과 후보를 다시 계산합니다. 선택 요약에서도 이전 답을 수정할 수 있습니다.
4. 결과에서는 자금별 **후보로 남은 이유**와 **다음 확인사항**을 먼저 봅니다. 여러 후보에 공통으로 남은 같은 조건은 한 번만 모아 표시합니다. 한도·금리·기간, 전체 판단 근거, 서류·절차는 펼쳐 확인합니다. 결과 복사에는 상세 내용도 포함되고, 인쇄할 때는 결과의 접힌 항목을 모두 펼칩니다.

처음에는 후보 목록을 접어 두어 현재 질문에 집중할 수 있습니다. 답변이 4개 이상이거나, 한 번 이상 답한 뒤 후보가 3개 이하로 줄거나, 결과에 도달하면 목록이 자동으로 열립니다. 직접 열고 닫은 상태가 우선하며 답변이 없는 처음 상태로 돌아가면 기본값으로 초기화됩니다. 선택지 아래 연관 자금은 계속 표시하며, 미충족 자금도 이유와 근거를 펼쳐볼 수 있습니다.

이름·연락처·주민등록번호·사업자등록번호를 입력하지 않습니다. 상담 답변은 현재 브라우저 탭의 메모리에서만 처리하며 서버로 보내거나 URL·브라우저 저장소에 기록하지 않습니다. 새로고침하면 상담 내용이 초기화됩니다.

## HTML 파일로 이용

[화면 상단의 HTML 파일 받기](https://pty9945-tech.github.io/SEMAS/download.html)를 누르면 다운로드 페이지가 열립니다. HTML 저장이 어려우면 ZIP 파일을 받아 압축을 풉니다. 대화의 `/workspace/...` 링크는 작업 환경 내부 경로여서 파일 전달용으로 사용하지 않습니다.

`동작센터-정책자금-상담-도우미.html` 파일 하나를 내려받아 Chrome 또는 Edge에서 열면 됩니다. 설치·로그인·서버·GitHub 접속 없이 상담하며, 다른 사람에게 파일을 그대로 전달할 수 있습니다. 화면·질문·정책자료·판단 규칙이 파일 안에 모두 포함됩니다. 공식 누리집이나 새 파일 다운로드 링크를 열 때는 인터넷이 필요합니다.

상담 답변은 파일에도 저장되지 않으며, 새로고침하거나 파일을 다시 열면 초기화됩니다. **HTML 파일은 자동 업데이트되지 않습니다.** 개선된 화면이나 갱신한 정책자료를 사용하려면 상단의 **새 HTML 파일** 링크에서 다시 받아 기존 파일을 교체합니다. 최신 접수 상황은 공식 자료로 별도 확인합니다.

화면과 다운로드 페이지에 파일 버전과 정책자료 확인일을 따로 표시합니다. 현재 화면·파일 버전은 **2026.10.21.2**(화면 개편일 **2026-10-21**), 정책자료 확인일은 **2026-10-15**입니다. 화면 개편일은 공고의 개정일이나 자료 재검증일을 뜻하지 않습니다.

개발자는 아래 명령으로 파일을 다시 만들고, 인터넷을 차단한 브라우저에서 파일을 직접 열어 검증할 수 있습니다.

```bash
npm run build:html
npm run test:html
```

완성 파일: `dist-html/동작센터-정책자금-상담-도우미.html`. 기존 웹사이트의 `dist/`와 별도로 생성하므로 두 방식으로 함께 배포할 수 있습니다.

검사 환경의 관리 정책이 `file://` 접근을 차단하면 직접 파일 열기는 미검증으로 표시하고, 동일한 HTML 내용을 브라우저 메모리에 불러와 오프라인 기능을 검사합니다. 브라우저 관리 정책은 변경하지 않습니다.

다운로드 페이지·HTML·ZIP을 포함한 웹 배포본은 Python 3가 설치된 개발 환경에서 `npm run build:download`로 생성합니다. ZIP은 생성 직후 CRC와 원본 HTML의 바이트 일치를 검증합니다.

## 개발·수정

Node.js 24.x 환경에서:

```bash
npm ci
npm run dev
npm test
npm run build:download
npm run test:e2e
```

`dist/`가 완성된 공개 사이트입니다. 서버 없이 정적 호스팅에서 동작하며 `/SEMAS/` 같은 하위 경로도 지원합니다.

| 파일 | 역할 |
| --- | --- |
| `policy/questions.js` | 질문·선택지 |
| `policy/rules.js`, `policy/engine.js` | 명시적인 AND/OR 조건 및 필요한 질문 선택 |
| `policy/agency-data.js`, `policy/direct-data.js`, `policy/sources.js` | 자금·서류·절차·금융조건·출처 |
| `policy/catalog.js` | 정책 데이터 결합 및 도움말 |
| `policy/release.json` | 화면·HTML 파일 버전, 개편일, 다운로드 주소 |
| `src/public-api.js` | 서버 요청 없이 브라우저 안에서 상담 계산 |
| `src/result-summary.js` | 후보별 이유 요약과 같은 조건 ID의 미확인 항목 묶기 |
| `src/main.jsx`, `src/styles.css`, `src/*-improvements.css` | 화면·반응형 디자인·접근성 |

정책을 수정한 뒤 `node scripts/export-policy-docs.js`로 조건표·분기표를 갱신합니다. 자료에 없는 요건·예외·금리·한도는 추가하지 않습니다.

화면이나 파일을 개편할 때는 `policy/release.json`의 버전·개편일을 갱신한 뒤 `npm run build:download`를 실행합니다. 정책자료 확인일은 실제 자료를 재검증했을 때만 변경합니다. 빌드는 같은 버전 정보를 웹사이트·단일 HTML·다운로드 페이지에 넣고 `dist/downloads/release.json`에도 기록합니다. 결과 요약은 표시 방식만 바꾸며, 질문이 같아도 조건 ID가 다르면 별도 항목으로 유지하여 자금별 요건·예외를 합치지 않습니다.
